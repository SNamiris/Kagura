# 资产浏览界面

首次启动时选择包含 `Library` 的上一级目录，例如 `G:\MMD`。Kagura 在后台扫描并建立索引，窗口内会显示加载状态。下次启动会读取保存的库根并检查变动。库根记录在 `%APPDATA%\Kagura\settings.json`，资产索引位于同目录下的 `index.sqlite`。

## 浏览

左侧可按资产类型、模型或场景种类、作者、标签及缺失项筛选。顶部搜索在停止输入 200 毫秒后生效。一个或两个 Unicode 字符使用 LIKE，三个及以上使用 FTS5。中间可切换网格与列表，按名称、添加时间、更新时间或评分排序，滚动时每页加载 200 条。

选中资产会打开右侧详情，可查看文件统计、授权、来源、标签、备注、引用及原始 JSON。歌曲详情按部件分组展示所属素材，并列出音频，可点击素材或关联版本跳转。素材详情可返回所属歌曲。「打开所在文件夹」在资源管理器打开当前资产目录。

底部显示库根、资产总数和上次扫描时间。「重新扫描」会同步外部改动。「检查」按检查项显示数量，并列出发现问题的位置与原因。

## 模型与动作解析

打开库或点击「重新扫描」后即可继续浏览。底栏显示后台解析进度；已经缓存的文件直接显示结果。资产内有多个模型或动作时，在详情的「模型解析」或「动作解析」下拉框切换文件。模型优先选中 manifest 声明的主变体。「模型头信息」可展开双语注释、编码、面数及物理计数。动作的最大帧号从零开始，秒数按每秒 30 帧折算，同一文件可以同时包含动作与表情。遇到读取失败，文件详情显示出错段、字节偏移和原因。

左侧「缺失贴图」筛出至少一个声明变体存在缺图的模型。「非标准骨骼（角色）」仅检查角色的声明变体，道具详情隐藏标准骨骼标记。两项分别命中 227 份模型和 120 份角色，组合命中 24 份角色。

## 重复

在顶部选择「重复」。总览显示哈希覆盖率、跨资产和同一资产内的重复量、扩展名分布。可设置读取线程数（1～4，默认 4），开始、暂停、继续或取消后台计算。离开此页可以继续浏览；下次运行会复用已完成文件的哈希。进度同时显示已读字节、文件数、速度和预计剩余时间。

进入跨资产或资产内文件组，展开可查看每份副本所属资产和相对路径。「打开所在文件夹」定位到该文件的实际父目录。小文件、通用 toon 和小型场景控制器可分别显示。整份重复和子集页使用全部已哈希负载，点击目录按钮打开相应资产根。可回收量按内容大小计算。确认两份资产的用途、引用和授权后，再决定是否进入后续整理草稿。

「导出 JSON」通过系统保存对话框将当前筛选的完整报告写至库外，包含跨资产组、资产内组、整份和子集。浏览、切换排除项或导出只读取资产库。

## 编辑与撤回

在详情面板选择「编辑」。点击星星设置 1～5 分，清除评分为 0（未评）。在标签框输入后按回车添加，也可以选择已有标签，点击标签旁的叉号移除。简评支持多行。来源链接对应 `source.url`，清空可移除链接。评分由用户在桌面界面填写。

保存会按上海当天日期更新 `updated`，并同步这一份资产的详情、列表与搜索索引。取消会放弃本次草稿。带有未保存修改时切换资产或离开编辑器，界面会先询问。若磁盘上的 manifest 在编辑期间已更改，保存会显示冲突。选择「重新加载」读取磁盘版本，再决定要保留的修改。

「最近修改」显示当前库的编辑记录。选择一条记录并确认撤回，即可恢复编辑前的完整文件。若当前文件的内容哈希已经改变，撤回会返回冲突，保留磁盘现状。

## Tauri 命令

| 命令 | 用途 |
|---|---|
| `get_settings`、`choose_library` | 读取保存的库根，或通过系统原生对话框选择文件夹。 |
| `open_library(root)` | 校验库根、打开或更新索引、保存设置，并返回库统计。 |
| `rescan`、`stats` | 增量扫描并返回资产和文件变更数，或读取当前库的统计与扫描时间。 |
| `parse_status`、`parse-progress` 事件 | 读取后台解析快照或订阅当前库的解析进度、完成与中断状态。 |
| `hash_status`、`start_hash(threads)`、`pause_hash`、`cancel_hash`、`hash-progress` 事件 | 控制可续算的 BLAKE3 任务，查询或订阅进度。 |
| `dedup_page(options, section, offset, limit)`、`export_duplicates(options)` | 浏览各类重复关系，或使用系统保存对话框导出完整 JSON 报告。 |
| `open_copy_folder(id, rel)` | 核验文件属于该资产，打开副本的实际父目录。 |
| `search(query, filters, sort, limit, offset)` | 返回当前页、总数和短词搜索标记。 |
| `get_asset(id)`、`song_children(songId)` | 读取完整 manifest、绝对路径、文件摘要、双向引用，或列出歌曲的素材。 |
| `open_folder(id)` | 从资产 ID 解析目录，验证其位于选中的 Library 内，再打开资源管理器。 |
| `run_check` | 运行核心库的一致性检查，返回各项计数和问题列表。 |
| `edit_asset(id, patch, baseHash)` | 以打开详情时的字节哈希为基准，校验并保存变更。 |
| `suggest_tags(query, limit)` | 从当前索引中补全标签。 |
| `list_edits(limit)`、`undo_edit(entryId)` | 读取当前库最近的编辑记录，或按记录编号撤回一次编辑。 |

前端命令类型由 ts-rs 导出至 `ui/src/generated/`。错误包含 `code` 和 `message`。

## 当前限制

编辑范围限于评分、标签、简评和来源链接，资产标识、识别键、其他元数据和资产文件均为只读。预览优先采用 manifest 的 `preview` 数组里首张可用图片，再查找根目录的 `preview.png`、`preview.jpg`。缺图时按资产类型显示占位图。文件摘要统计属于该资产的文件，详情另列出 manifest 声明的变体、部件和文件。

asset 协议初始放行清单为空。应用只为当前库中核验过的具体预览图片授权。离开已授权预览的库时会撤销旧库权限，再次切回该库时应用可能自动重启一次，从保存的库根恢复。短词 LIKE 的大小写折叠限于 ASCII。

## 实测（2026-11-24，Windows WebView2）

空缓存首次打开真实库用时 2.403 秒，无变化重扫 0.457 秒。ECHO、小苹果、ミク 分别命中 11、1、72 条。「模型」与「作者不明」组合命中 1,289 条。库检查覆盖 8,824 份资产，九项计数均为零。

在 1280 × 800 的 release 窗口，用 `requestAnimationFrame` 每帧将网格向下移动约 0.23 个视口。29.65 秒滚到第 8,824 条，共载入 45 页，同时渲染最多 66 张卡片。1,756 个帧间隔的中位数为 16.7 毫秒，P95 和 P99 均为 16.8 毫秒，最长 100.1 毫秒。出现过短暂停顿，全程没有结果区只剩占位卡的帧。

在桌面编辑器中给场景「ドーム黒」添加 `kagura-test` 后，搜索从 0 条变为 1 条。通过「最近修改」撤回后，搜索回到 0 条，磁盘上的 502 字节与原件完全一致。保存后和撤回后的全库检查均为 8,824 份记录、0 个问题。
